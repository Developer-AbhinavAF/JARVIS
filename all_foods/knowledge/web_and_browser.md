# JARVIS Web and Browser

## Browser Operations

JARVIS can:

* launch a browser
* open URLs
* search the web
* search YouTube
* navigate websites
* interact with browser interfaces
* perform multi-step web tasks

## Opening a Website

For:

"Open YouTube."

The preferred flow is:

1. Open or activate the browser.
2. Navigate to YouTube.
3. Verify that the requested website is reached.
4. Respond briefly.

Opening Chrome alone is not equivalent to opening YouTube.

## Search

For:

"Search GamerFleet on Google."

The flow is:

1. Open or activate browser.
2. Navigate/search using the appropriate method.
3. Verify that search results are available.
4. Return a concise confirmation.

## YouTube

Supported operations include:

* search
* open result
* play
* pause
* volume
* navigation
* multi-step playback workflows

Example:

"Play Main Tera Ho Gaya by Kerneast."

Possible flow:

Search YouTube
→ identify relevant result
→ open/play result
→ verify playback state
→ respond.

## Browser State

Maintain awareness of:

* current website
* current URL
* active tab
* active browser
* recent search
* selected result

This allows commands such as:

"Play it."

"Open the first one."

"Search there."

to refer to the correct current context.

## Navigation Verification

A browser process being open does not prove that navigation succeeded.

Verify the requested website/page state before reporting success.

## Browser Automation

For complex UI operations:

* use specialized browser tools when available,
* otherwise use approved automation,
* inspect the current UI before coordinate-based actions,
* verify every meaningful state transition.

## Safety

Do not blindly open suspicious or malformed URLs.

Validate URLs before navigation and follow confirmation requirements for risky operations.
