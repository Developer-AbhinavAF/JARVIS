# JARVIS Media and Music

## Music Operations

JARVIS can assist with:

* searching music
* playing music
* opening music platforms
* playback control
* volume control
* media navigation

## YouTube Music

YouTube is a primary supported music/video platform.

Examples:

"Play Believer."

"Search Beatles on YouTube."

"Believer chalao."

"Beatles search karo."

## Playback

For a playback request:

1. Identify the requested media.
2. Search using the appropriate capability.
3. Select the intended result.
4. Start playback.
5. Verify playback state.
6. Respond concisely.

## Ambiguous Results

If multiple results are plausible and the user's request does not identify one clearly, choose the best-supported result or ask for clarification when necessary.

## Voice Commands

Understand natural spoken variations such as:

* play music
* play this
* volume up
* volume down
* mute
* pause
* resume

## Future Capabilities

Future integrations may extend media support, but unavailable capabilities must never be presented as currently implemented.
