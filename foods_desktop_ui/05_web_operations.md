# Web Operations and Browser Integration

The UI supports web browsing and online operations through tools.

## Web Capabilities

### Web Search
- DuckDuckGo search integration
- Real-time search results
- Multiple result types (web, images, videos)
- Search history tracking

### YouTube Integration
- Video information retrieval
- YouTube search
- Video download capability
- Channel information

### Instagram Integration
- User profile information
- Post retrieval
- Engagement metrics
- User activity tracking

### Browser Automation
- URL opening
- Tab management
- Navigation control
- History access

## Web Operation Guidelines

1. **Search Strategy**: Use effective search queries
2. **Result Filtering**: Present relevant results
3. **Link Verification**: Check link safety when possible
4. **Content Summarization**: Summarize web content
5. **Action Suggestions**: Suggest follow-up actions

## Search Best Practices

### Query Construction
- Use specific, targeted keywords
- Include relevant modifiers
- Use quotes for exact phrases
- Exclude terms with minus sign

### Result Presentation
- Show top 3-5 most relevant results
- Include titles and descriptions
- Provide direct links
- Summarize key information

### Source Verification
- Check source credibility
- Note publication dates
- Cross-reference when important
- Warn about potentially unreliable sources

## Example Web Interactions

### Web Search
User: "What's the latest Python version?"
Response: (performs search) "The latest stable Python version is 3.12.3, released in April 2026. It includes several performance improvements and new features."

### YouTube
User: "Find Python tutorial videos"
Response: (searches YouTube) "I found several Python tutorial videos. The top result is 'Python for Beginners' with 2.5M views. Would you like me to open it or download it?"

### Instagram
User: "Get info about natgeo account"
Response: (fetches Instagram data) "National Geographic (@natgeo) has 270M followers, 42K posts, and shares stunning photography and nature content."

## Web Safety

1. **URL Safety**: Warn about suspicious URLs
2. **Privacy**: Respect user privacy
3. **Content Filtering**: Avoid inappropriate content
4. **Download Safety**: Warn about file downloads
5. **Phishing Protection**: Be alert for phishing attempts
