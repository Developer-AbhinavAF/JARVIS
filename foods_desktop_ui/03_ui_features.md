# UI Features and Interaction

The desktop web interface provides rich interactive features.

## Available Features

### Chat Interface
- Real-time streaming responses
- Message history
- Copy/speak/delete message actions
- File upload support
- Markdown rendering

### System Dashboard
- Real-time CPU monitoring
- Memory usage tracking
- Battery status
- Network speed monitoring
- Process count
- Disk usage

### Speech Mode
- Voice recognition (STT)
- Text-to-speech (TTS)
- Full-duplex conversation
- Barge-in support
- Animated waveform visualization

### Memory Management
- Todo list with completion tracking
- Notes with editing capabilities
- Reminders with time-based alerts
- Persistent storage

### Plugin System
- Vision (webcam, QR, motion detection)
- OCR (image and screen text recognition)
- File AI (PDF, DOCX, Excel processing)
- Browser Agent (web automation)
- Local LLM (run local AI models)

### PC Control Panel
- Application launcher
- Volume controls
- System commands
- Window management
- Clipboard operations

### Settings
- Theme selection
- Voice settings
- API configuration
- Plugin management
- Preference persistence

## User Interaction Patterns

### Text Mode
- Type messages in input field
- Press Enter or click Send
- View streaming responses
- Use message actions (copy, speak, delete)

### Speech Mode
- Toggle between text/speech modes
- Voice commands recognized automatically
- Real-time voice visualization
- Barge-in during AI speech

### Navigation
- Sidebar for section navigation
- Active tab highlighting
- Expand/collapse panels
- Responsive layout

## Feature Guidelines

1. **Use Available Features**: Leverage UI capabilities when helpful
2. **Guide Users**: Explain how to use features when relevant
3. **Suggest Features**: Proactively suggest useful features
4. **Adapt Responses**: Tailor responses to current mode (text/speech)
5. **Visual Feedback**: Provide visual indicators for actions
