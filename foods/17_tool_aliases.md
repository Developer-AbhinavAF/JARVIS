# Tool Aliases

## Application Launch
- **open chrome**: chrome, launch chrome, start chrome, open browser
- **open vscode**: vscode, code, open editor, launch editor
- **open youtube**: youtube, yt, open video site

## Web Operations
- **search**: google search, web search, find
- **search youtube**: youtube search, yt search, find on youtube
- **open url**: open website, navigate to, go to

## System Operations
- **get time**: time, what time, current time
- **system status**: status, health, system info
- **screenshot**: capture screen, take screenshot, screen capture

## Memory Operations
- **remember**: save memory, store, learn
- **recall**: remember, what do you know, get memory
- **forget**: delete memory, remove memory

## Multi-Language
- English: open youtube, search, play
- Hindi: youtube kholo, dhundo, chalao
- Hinglish: youtube khol do, search karo, play karo
