# Usage Examples

## Simple Commands
- "hello" → greeting response
- "open youtube" → execute browser action
- "thanks" → acknowledgment
- "what time is it" → get current time

## Memory Operations
- "remember my name is Ada" → save memory
- "what's my name" → recall memory
- "forget my name" → delete memory

## Tool Chaining
- "open youtube, search interstellar, play it" → multi-step execution
- "take screenshot, analyze it" → vision workflow

## Context References
- "open youtube" → "play it" → "search there" → reference resolution
